# 私人记录前端（无服务器版）

按教程生成的最小可用项目：HTML 负责显示和输入，Supabase 负责存数据，
不需要 MCP，不需要后端。

## 文件结构

```
private-frontend/
├── index.html        入口页，列出各个功能模块
├── diary.html         日记页（已实现读取 + 新增）
├── manifest.json       PWA 配置，用于"添加到主屏幕"
└── assets/
    ├── style.css        共享样式（暖白背景、卡片、圆角）
    ├── config.js        Supabase 连接信息，填这里
    └── icon-192.png / icon-512.png   需要你自己补一对图标（manifest 里引用了，仓库里没放实际图片）
```

## 三步跑起来

### 1. 建 Supabase 项目和表

在 [supabase.com](https://supabase.com) 新建项目，记下 **Project URL** 和
**anon public key**（Project Settings → API）。

进入 SQL Editor，执行：

```sql
create table diaries (
  id bigint generated by default as identity primary key,
  content text not null,
  mood text,
  created_at timestamptz default now()
);
```

### 2. 开 RLS 权限（测试阶段用宽松策略）

```sql
alter table diaries enable row level security;

create policy "allow anon read diaries"
on diaries for select
to anon
using (true);

create policy "allow anon insert diaries"
on diaries for insert
to anon
with check (true);
```

> 这是入门测试策略：任何知道网址的人都能读写这张表。
> 正式使用前应该收紧权限（加登录、限制 anon 权限）。

### 3. 填连接信息

打开 `assets/config.js`，把 `SUPABASE_URL` 和 `SUPABASE_ANON_KEY`
换成你自己的值（只填 anon public key，**千万不要**填 service_role key）。

## 本地预览

不要直接双击 HTML 打开（`import`/module script 在部分浏览器上会因安全策略失败）。
推荐用 VSCode + Live Server 插件，右键 `diary.html` → Open with Live Server。

## 部署

把整个 `private-frontend/` 文件夹拖进 Netlify（Deploy manually），或连接
Vercel / GitHub Pages 部署，会得到一个 `https://xxx.netlify.app` 之类的网址，
手机和电脑都能打开。

**改完代码后要记得重新部署**——本地文件改了，线上网站不会自动更新。

## 添加到手机桌面（PWA）

部署上线后用手机浏览器打开网址，选择"添加到主屏幕"，就会有一个图标，
点开接近全屏 App 的体验。当前只做了 `manifest.json`（基础配置），
离线缓存的 `sw.js` 是进阶功能，之后需要再加。

## 常见问题

| 现象 | 多半原因 |
|---|---|
| `new row violates row-level security policy` | RLS 开了但没配 insert 策略 |
| `relation does not exist` | 表名写错 |
| `column does not exist` | 字段名写错 |
| 页面死活不更新 | 检查有没有重新部署；如果做了 Service Worker，去开发者工具里 Unregister 后清缓存 |
